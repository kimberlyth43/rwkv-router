## ⚙️ How It Works

### The Intelligent Routing

When your software makes an AI request, rwkv-router quickly analyzes it. It looks at:
- **Task type:** Is this a simple chat, code generation, translation, or something else?
- **Content complexity:** How long and detailed is the request?
- **Your usage history:** What has worked best for similar requests before?

Based on this, it routes the request to the cheapest AI model that can still deliver excellent results. Sometimes it uses a small, fast, low-cost model. Other times it uses a premium model. It balances quality and cost automatically.

### Self-Evolution Explained

The router doesn't stay static. Over time, it logs which decisions worked well and which didn't. After about 100 requests, it enters R1 stage - basic learning. By R2, it's noticeably sharper. After 500+ requests, it reaches R3 - near-perfect routing decisions. This happens entirely on your machine, no cloud involvement whatsoever.

### Token Savings Breakdown

Tokens are how AI services measure usage - each word costs fractions of a cent. The router reduces token consumption by:
1. Sending only essential context, not extra text
2. Using smaller models for simple tasks (70% of tasks)
3. Caching repeated prompts so you don't pay twice
4. Combining multiple requests when beneficial

## ⚠️ Troubleshooting

### Router shows "Offline"
Check that no other program is using port 8080. Open the Troubleshooting tab and click "Check Port" - it will suggest a fix.

### No savings showing after a week
Some users need to configure their applications properly. Use the built-in "Test Connection" button to verify each app's connection. Look for green checkmarks next to your connected programs.

### Key errors
Re-enter your API keys, making sure there are no extra spaces. Keys are case-sensitive.

Go to Settings > Performance and select "Lightweight Mode." This reduces memory usage by up to 60% while keeping most benefits.
